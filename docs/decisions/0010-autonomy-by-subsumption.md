# 0010 — Autonomy is earned by mechanical subsumption, never granted by reputation

## Decision

A human gate retires only when a mechanical check subsumes it and that check
has been green for a written number of cycles. The maturity ladder in
`docs/MATURITY.md` is documented in full from the start even though only its
lowest rungs are exercised.

## Rationale

Without this rule autonomy arrives by drift: nobody decides that an agent
may merge unreviewed work, review just gradually stops happening, and the
first serious failure has no one to attribute it to. Naming the current rung
makes the level of trust a written, revisable claim.

The mirror failure is promotion by optimism — granting a rung because the
agent has been doing well lately rather than because a check now catches the
class of mistake the human gate was catching. Tying promotion to a named
check and a counted number of green cycles removes the judgement call in
both directions, which is also why demotion has to be written down with the
same precision. Keeping the higher rungs on paper before they are reachable
is what makes today's rung a deliberate position rather than the only one
anyone imagined.
